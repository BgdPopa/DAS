# DAS - Deskly AuthX

Proiect pentru disciplina Dezvoltarea Aplicatiilor Software Securizate.

Aplicatia Deskly AuthX simuleaza un sistem intern de autentificare si gestionare de tichete. Proiectul este construit in doua versiuni:

- `vulnerable` - versiunea initiala, cu vulnerabilitati intentionate;
- `secure` / `main` - versiunea securizata, dupa aplicarea controalelor de securitate.

Stack tehnologic:
- Flask
- SQLite
- SQLAlchemy
- Jinja2
- Bootstrap 5
- bcrypt
- Flask-Limiter

Scopul proiectului este demonstrarea ciclului: build, hack, secure, re-test.
